# Problem Statement
Small cinemas often track bookings on paper, which causes double-booked
seats and wrong bill totals. [Add 2-3 lines in your own words here.]

# Scope
A command-line system for movie management (admin) and ticket booking
(customer), with per-movie seat selection, discounts, and saved data.

# Target Users
- Cinema admin (adds and removes movies)
- Customers (book tickets)

# High-level Features
- Admin login with a salted, hashed password
- Add / remove / view movies
- Per-movie seat map and booking
- Adult / Student / Child pricing with student and group discounts
- Data saved in JSON files, activity written to a log file
